# Smart Mail Dashboard (LOTUS)

Локальная система автоматического сбора, интеллектуального триажа и визуализации входящей почты руководителя из клиента Lotus Notes (Executive Notes AI Triage). Спецификация — в [docs/spec.md](docs/spec.md), описание данных — в [docs/data.md](docs/data.md).

## Запуск

1. Запустить клиент Lotus Notes и оставить его открытым.
2. Запустить [`run.bat`](run.bat) — он остановит старый процесс, запустит [`notes_gemini.py`](notes_gemini.py) и откроет браузер на `http://127.0.0.1:8765`.
