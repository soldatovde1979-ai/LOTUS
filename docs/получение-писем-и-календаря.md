# Получение писем и календаря из Lotus Domino (проверено 08.10.2026)

Вся цепочка проверена на живой почте: `CN=Mail8/O=svo`, база `mail\desoldatov.nsf`,
1832 письма во «Входящих», 2340 записей в календаре.

## 1. Как это работает (архитектура)

```
Python ──COM──> установленный клиент HCL Notes ──NRPC:1352──> сервер Mail8 (LAN: mail.svo.aero = 192.168.75.69)
```

- Прямого сетевого протокола у Python нет: NRPC — закрытый бинарный протокол Domino,
  повторить его вне клиента невозможно. COM — единственный программный мост.
- Пароль клиента Notes НЕ нужен, если клиент уже запущен и залогинен;
  `NotesSession.Initialize()` подхватывает открытую сессию.
- Удалённо (без офисной сети) это НЕ работает: traveler.svo.aero порт 1352 открыт,
  но базы по NRPC не отдаёт (проверено: `IsOpen=False` для любых баз). Нужен VPN до `mail.svo.aero`.

## 2. Рабочий код: ПИСЬМА (Входящие)

Проверено на реальной базе. Важно: итерация только через `GetNthDocument(i)`,
метод `GetNextDocument` в COM-обёртке gen_py не работает (AttributeError).

```python
import win32com.client

ses = win32com.client.Dispatch("Lotus.NotesSession")
ses.Initialize()                                   # подхватывает залогиненный клиент Notes

db = ses.GetDatabase("CN=Mail8/O=svo", "mail\\desoldatov.nsf")   # открывает сервер по NRPC
view = db.GetView("($Inbox)")                      # стандартное представление входящих
print("Всего входящих:", view.EntryCount)          # 1832

for i in range(1, 11):                             # последние 10 писем
    doc = view.GetNthDocument(i)                   # ТОЛЬКО так (не GetNextDocument!)
    if doc is None:
        break
    posted = (doc.GetItemValue("PostedDate") or [""])[0]   # дата: 2025-10-20 08:55:03+00:00
    frm    = (doc.GetItemValue("From") or [""])[0]         # CN=Zakhar V Koshelev/O=SVO
    subj   = (doc.GetItemValue("Subject") or [""])[0]      # тема
    body_item = doc.GetFirstItem("Body")                   # rich text -> простой текст
    body_text = body_item.Text if body_item is not None else ""
```

Проверенные поля письма: `PostedDate`, `From`, `Subject`, `Body` (текст через `.Text`),
вложения — `doc.HasItem("$File")`.

## 3. Рабочий код: КАЛЕНДАРЬ

```python
cal = db.GetView("($Calendar)")                    # 2340 записей на 08.10.2026
print("Всего записей календаря:", cal.EntryCount)

for i in range(1, 11):
    doc = cal.GetNthDocument(i)
    if doc is None:
        break
    start = (doc.GetItemValue("StartDateTime") or [""])[0]  # 2023-10-19 12:00:00+00:00
    end   = (doc.GetItemValue("EndDateTime") or [""])[0]    # 2023-10-19 14:00:00+00:00
    subj  = (doc.GetItemValue("Subject") or [""])[0]        # «Резерв»
    chair = (doc.GetItemValue("Chair") or [""])[0]          # CN=Dmitriy E Soldatov/O=SVO
    loc   = (doc.GetItemValue("Location") or [""])[0]
    atype = (doc.GetItemValue("AppointmentType") or [""])[0]  # 0 = встреча
```

Проверенные поля события: `Form` (=`Appointment`), `StartDateTime`, `EndDateTime`,
`Subject`, `Chair`, `Location`, `AppointmentType`.

## 5. Ограничения

1. Требуется установленный и запущенный клиент HCL Notes на той же машине.
2. Требуется сеть до Mail8: в офисе — `mail.svo.aero` (192.168.75.69:1352), из дома — VPN.
3. Traveler/HTTPS-канал писем не отдаёт (база не опубликована, iNotes выключен — 500/403/404).
   Открытие HTTPS-доступа — задача администратора Domino.
4. `GetNextDocument` не работает через gen_py — только `GetNthDocument`.
