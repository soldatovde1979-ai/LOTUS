# Состояния письма и их размещение в интерфейсе

Каждое письмо — это набор **независимых осей-фактов** (данные), поверх которых дашборд строит **представления** (как на них смотреть). Факты меняет либо Lotus Notes, либо AI-разбор, либо руководитель кнопкой; представления — только комбинации фильтров.

## 1. Оси данных (факты письма)

Хранятся в `dashboard_data.json`, заполняются при сборе ([`notes_gemini.py`](../notes_gemini.py)) и AI-разборе ([`prompt_template.txt`](../prompt_template.txt)).

### 1.1. Отработка — `workState` (new / wip / done)
Метка «моя работа» — я это закрыл. Поле `stateAt` хранит момент отметки (для «Отработано сегодня»).
- `new` — не разобрано
- `wip` — в работе (черновик ответа создан, письмо отложено в работу)
- `done` — отработано

### 1.2. Прочтение — `isRead`
Метка Notes «я это открыл». Если Notes не отдаёт метки, новизну считает сам дашборд (см. `read_detection`), и ось называется «Новое / Было раньше».

### 1.3. Ответ — `needsReply`, `isReplied`, `draft`, `replies[]`
- «Нужен ответ» = `needsReply && !isReplied`
- «Отвечено» = `isReplied` (в `replies[]` — отправленные из Notes)
- «Черновик» = `draft` (создан из дашборда, ещё не отправлен)

### 1.4. Приоритет — `priority` (1 / 2 / 3)
- `1` — Срочно (P1): E_TOP, горящее согласование, критичный инцидент, просрочка
- `2` — Важное (P2): рабочие вопросы, согласования без горящего срока
- `3` — Остальное (P3): информирование, рассылки

### 1.5. Тип письма — `kind`
Из `prompt_template.txt`: Согласование / Поручение / Вопрос / Встреча / Информирование. «Информирование» на ярлыках не показывается, но доступно как фильтр «Тип».

### 1.6. Отправитель — `senderTag`, вычисляемые `isTop` / `isDir` / `isSystem`
- `E_TOP` — высшее руководство (списки `e_top` / `e_top_emails` из `set.ini`)
- `E_DIR` — директора и руководители (`e_dir` / `e_dir_emails`)
- `isSystem` — автоответчики, порталы, 1С, службы поддержки (по адресу и имени)

### 1.7. Срок — `deadline`, `overdue`
`deadline` — дата (ГГГГ-ММ-ДД), `overdue` — true, если срок прошёл или письмо сообщает о просрочке.

### 1.8. Дополнительные оси разбора (есть в данных, участвуют в фильтрах)
- `waitingOn` — «me» (мяч у руководителя) / «them» (ждём других) / «none»
- `risk` — цена пропуска: high / medium / low
- `carriesAction` — требует ли письмо действия вообще
- `ask` — что конкретно требуется от руководителя (до 8 слов)
- `suggestedReply` — проект ответа от AI

## 2. Представления: как смотреть на письма

Все фильтры комбинируются через **И** (AND). Итоговая выборка:

```
Очередь  И  Фокус(пресет)  И  От кого  И  Тип  И  Непрочитанные  И  Поиск  →  сортировка
```

### 2.1. Очередь — главная навигация (верхняя полоса + чипы)
Отражает жизненный цикл работы, поэтому это одиночный выбор из пяти:

| Очередь | Условие |
|---|---|
| Сейчас | `priority===1` ИЛИ руководство ИЛИ нужен ответ, и не в работе, и не отработано |
| Потом | не срочное, не в работе, не отработано |
| В работе | `workState === 'wip'` |
| Отработано | `workState === 'done'` (в счётчике сверху — за сегодня) |
| Все | без ограничения |

### 2.2. Фокус — быстрые пресеты (панель «Фокус», взаимоисключающие чипы)
Покрывают частые вопросы «покажи только…». Счётчик на чипе = сколько писем подходит **внутри активной очереди**.

| Пресет | Условие |
|---|---|
| Все | без ограничения |
| Требуют ответа | `needsReply && !isReplied && workState !== 'done'` |
| Срочно P1 | `priority === 1` |
| Важное P1–P2 | `priority === 1 || priority === 2` |
| Просрочено | `overdue` |
| Руководство | `isTop` |
| Ждём других | `waitingOn === 'them'` |

### 2.3. От кого (выпадающий список)
любой отправитель / высшее руководство / директора / руководство и директора / только люди / только системы.

### 2.4. Тип (выпадающий список)
любой тип / согласование / поручение / вопрос / встреча / информирование.

### 2.5. Непрочитанные (тумблер в верхней полосе)
Показывает только `!isRead` (или «новых с прошлого сбора», если новизну считает дашборд).

### 2.6. Поиск и сортировка
Текстовый поиск по теме, автору, адресу и сути. Сортировка: по важности (умная), сначала новые, по отправителю.
