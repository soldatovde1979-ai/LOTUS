## 2026-08-31 20:08 — [feat] Цепочки писем, «Отработать все», баланс DeepSeek, сводка без отработанных

**🎯 Цель сессии:** Свернуть переписку одной темы в цепочки, добавить массовую отработку старых писем, показывать остаток средств и не тащить отработанные письма в сводку.

### 🛠 Внесенные изменения:

**Файл:** `notes_gemini.py`
- **ЧТО:** `group_threads()` проставляет `threadRoot` (голова цепочки — первый элемент). Добавлены пакетные `set_work_states()` / `set_docs_read_status()`; `/api/set-state` и `/api/mark-read` принимают массив `unids`. Добавлены `fetch_balance()` и `GET /api/balance` (`{base_url}/user/balance`). `build_digest()` исключает отработанные (`done`) письма из сводки. `/api/settings` и `/api/save-settings` поддерживают `auto_done_days`.
- **ПОЧЕМУ:** Пометка первого элемента цепочки должна наследоваться всей ветке (вложенный — только себе); «Отработать все» закрывает письма старше срока из настроек, кроме «В работе»; остаток средств виден в настройках; сводка — только про активное.

**Файл:** `index.html`
- **ЧТО:** Цепочки: `rebuildChainMap()`, `collapsedChains` (по умолчанию свёрнуты), `chainHTML()`/`rowHTML()`, наследование пометок через `chainMembersOf()`, клавиатурная навигация по реально показанным строкам. Кнопка «Отработать все» в шапке (`doneAllOld()`), поле настройки `auto_done_days`, вывод баланса в настройках (`loadBalance()`).
- **ПОЧЕМУ:** Требование: по умолчанию цепочка свёрнута; первый элемент помечает всю цепочку, вложенный — только себя; кнопка массовой отработки рядом с получением писем.

**Файл:** `set.ini`
- **ЧТО:** Добавлен `[UI] auto_done_days = 1` — сколько дней «оставить» не отработанными при «Отработать все».
- **ПОЧЕМУ:** Настройка периода массовой отработки, по умолчанию 1 день.
