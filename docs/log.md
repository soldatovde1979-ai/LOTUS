## 2026-09-01 14:50 — [feat] Кнопка «Перейти в ДО»: ссылка на задачу 1С:ДО открывается из дашборда

**🎯 Цель сессии:** У писем документооборота («Задача: Рассмотреть …», «Ссылка на задачу 1С:ДО: …») кнопка рядом с «Открыть в Lotus» должна открывать саму задачу в 1С:ДО. Инфраструктура (поле `do_url`, кнопка) уже была, но ссылка не извлекалась — `do_url` оставался пустым для всех писем.

### 🛠 Внесенные изменения:

**Файл:** `notes_gemini.py`
- **ЧТО:** `URL_RE` теперь понимает протоколы `e1c://` и `v8://` (клиент 1С) — ссылки вида «Ссылка документ ЕRP УХ: e1c://server/...» перестали теряться. Извлечение гиперссылок перенесено в DXL-выгрузку с `MIMEOption = 1` (DXL_MIME_KEEP_AS_IS), чтобы HTML-часть интернет-писем не вырезалась и `href`-ы были видны; добавлены парные паттерны `<a href>…</a>` / `<urllink href>…</urllink>` с `html.unescape()`. `extract_do_url()` ранжирует кандидатов с приоритетом на ссылку именно на ЗАДАЧУ (бонус за «задач» в адресе или якорном тексте «Ссылка на задачу»), а не на документ.
- **ПОЧЕМУ:** раньше ссылка на задачу не извлекалась (пустой `do_url` → кнопки нет): `URL_RE` не ловил `e1c://`, `_urls_from_mime` видел только текст без `href`, а DXL-экспорт по умолчанию вырезал HTML-часть MIME-письма.

**Файл:** `index.html`
- **ЧТО:** Кнопка переименована в «Перейти в ДО» и поставлена непосредственно рядом с «Открыть в Lotus» (и для «Отработано», и для активного письма). `openDo()` открывает `http(s)` в новой вкладке, а ссылки с нестандартным протоколом (`e1c://`, `notes://`) отдаёт браузеру якорным кликом — он сам вызовет зарегистрированный обработчик (клиент 1С).
- **ПОЧЕМУ:** требование пользователя — кнопка рядом с «Открыть в Lotus», открывающая ссылку задачи; `window.open` для нестандартных протоколов ненадёжен (попадает под блокировку).

**Файл:** `scripts/probe_do_links.py` (новый)
- **ЧТО:** Диагностика извлечения ссылок 1С:ДО: для писем с упоминанием 1С:ДО (или конкретного UNID) печатает, что видит каждый источник — текст, MIME, DXL — и итоговый `do_url`.
- **ПОЧЕМУ:** проверить фикс на реальных письмах без запуска всего сбора.

**Файлы:** `docs/spec.md`, `docs/log.md`
- **ЧТО:** В спецификацию добавлен раздел 4.9 «Ссылки на задачи 1С:ДО», журнал обновлён.
- **ПОЧЕМУ:** актуализация архитектурной документации.
