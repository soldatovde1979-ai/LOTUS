## Известные проблемы (Known Issues)
1. **Блокировка потока (Thread Locking)**: Метод `do_POST` сервера `http.server` синхронный. Во время AI-триажа (который может занимать 5-15 секунд) сервер не принимает другие запросы. Реализован `ANALYSIS_LOCK`, чтобы избежать параллельных запусков, но это костыль.
2. **Безопасность Lotus Notes**: Если Lotus Notes заблокирован (введен пароль базы), COM-интерфейс может зависнуть, ожидая ввода пароля.
3. **Хрупкость парсинга JSON от AI**: Текущий regex `re.search(r'(\{[\s\S]*\}|\[[\s\S]*\])', raw_text)` работает хорошо, но может дать сбой, если AI вернет markdown с пояснительным текстом внутри JSON-строки.
