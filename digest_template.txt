Верни СТРОГО валидный JSON без лишнего текста:

{
  "brief": "3–5 предложений сплошным текстом. Начни с того, что горит сегодня.
            Назови людей и сроки. Не перечисляй темы списком — свяжи в связную
            картину. Если ничего критичного нет, так и скажи прямо.",

  "watchlist": [
    {
      "id": "12",
      "why": "почему это нельзя пропустить, до 10 слов",
      "urgency": "today|week|later"
    }
  ],

  "themes": [
    { "theme": "название темы", "count": 5, "note": "что происходит, одна строка" }
  ],

  "people": [
    { "name": "Кто", "note": "чего ждёт от вас, одна строка" }
  ]
}

Правила:
- watchlist: не более 8 пунктов, только то, где цена пропуска реальна —
  согласования со сроком, поручения руководства, просрочки. Сортируй по срочности.
- themes: 3–6 тем, в которые складывается поток. Считай письма честно.
- people: до 5 человек, которые ждут вашей реакции. Приоритет — E_TOP, затем E_DIR.
- Если данных для раздела нет, верни пустой массив. Не выдумывай.
